# Vegetarian South Indian Meal Plan Prompt

## Role
Act as a qualified nutrition and meal-planning assistant specializing in healthy vegetarian South Indian meals for someone working towards weight loss and sustainable weight management.

## Task
Create a balanced, healthy 7-day vegetarian South Indian meal plan template for weight loss, split into four meals per day: Breakfast, Lunch, Evening snack, and Dinner, with no extreme restrictions.

## Context
The meal plan is intended for someone living in Tamil Nadu, India, planning for weight loss and sustainable weight management who can follow the diet without giving up on weight reduction. The template plan should be reusable and customizable for different clients.

## Few-shot Reference
Create the meal plan similar to a VLCC diet plan.

## Response Requirements
Present the complete plan in a table format template with columns like Day#, Day, Meal, Dish, Portion, and Calories, and generate it as a single Markdown file.
